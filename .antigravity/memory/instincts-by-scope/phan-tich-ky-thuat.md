### [I125] Bài chỉ báo/mô hình: bảng phân biệt mẫu dễ nhầm, tín hiệu có xác nhận
- Mở bằng phân biệt với mẫu dễ nhầm (bảng đối sánh: Stochastic vs StochRSI, Hammer vs Hanging Man…); mục công thức chỉ nói biến số và cách tính. Tín hiệu luôn kèm điều kiện xác nhận (volume ≥ 1,5× MA20 hoặc nến xác nhận), điểm cắt lỗ, R:R ≥ 1:2, nhắc T+2. Code (AFL, Pine) trình bày bằng bảng 2 cột, không code block.
