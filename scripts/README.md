# Helper Scripts — tra cứu khi cần

Bảng tham chiếu đầy đủ (chuyển từ `CLAUDE.md` ngày 2026-11-10 để không nạp ~10 KB vào mọi session). Việc thường ngày đã có ở bảng "Việc → Làm" trong `CLAUDE.md`; chỉ mở file này khi cần cờ / chi tiết của 1 script (hoặc chạy `python <script> --help`).

| Script | Dùng để |
| :--- | :--- |
| `scripts/qa_lint.py <file> [--outline] [--original] [--cta] [--fix] [--json] [--log]` | Lint deterministic. **Hình thức:** CL1/2/3/6, link, GEO, word count. **Thực chất:** `coverage` (`ENT-missing` thuật ngữ ≥ 3 đối thủ đều dùng — đọc cache SERP theo keyword; `IG-missing` proof của Information_Gain; `PAA-*`; `DUP-h2`/`DUP-faq` trùng bài Final khác) và `trust` (`SRC-missing` trích văn bản/số liệu mà 0 link nguồn trong `source-whitelist.md`; `SRC-unshown`; `YMYL-disclaimer`; `EEAT-firsthand`; `CL5-fact`). `GEO-h2-answer` = câu đầu mỗi H2 trả lời ngay. Score 0–100 gồm 7 nhóm. Exit 1 = FAIL. `--cta` bật thêm 6 check CTA-* (chưa mặc định — corpus chưa backfill banner). |
| `scripts/outline_lint.py <outline.md> [--json]` | **Gate của `/outlining`** — khung bài khớp SERP (tính lại từ cache SERP: toplist / how-to / định nghĩa…), toplist có số N, Thesis, `ENT-outline` (phủ ≥ 70% thuật ngữ đối thủ đều dùng), `IG-shape`/`IG-not-new` (Information_Gain ≥ 2 mục có `h2` + `proof`), `SERP-paa-fake` (PAA ghi nguồn Google nhưng không có trong cache), `DATA-source` (dữ kiện thiếu URL nguồn), tổng Target vs Word_Count, Title/Meta/Sapo có DSC, keyword trong H2, Kết luận/Bridge/FAQ, "Câu hỏi người đọc" + "Ý chính" từng H2, 3–6 link, `[CẦN XÁC NHẬN]`, số liệu năm hiện tại, SERP degraded. Exit 1 = FAIL. |
| `scripts/qa_gate.py <draft> [--cta] [--fix] [--all] [--changed] [--mark-qg]` | **1 lệnh cho tầng A+B+dữ liệu** — 1 dòng/tầng (tầng A kèm điểm coverage · trust + độ phủ thuật ngữ / Information_Gain / link nguồn) + chỉ lỗi CRITICAL/MAJOR; cảnh báo khi bài không có outline, dừng ở tầng FAIL đầu; outline tự tìm (kể cả trong archive). `--mark-qg` lưu mốc sau khi Quality Guardian duyệt, `--changed` in đúng các đoạn sửa từ mốc đó (vòng 2 QG không đọc lại cả bài). |
| `scripts/article_snapshot.py <slug> --stage outline\|gate2\|final` · `--diff` · `--path outline` | Lưu từng stage vào `knowledge/4-content/archive/<slug>/` (outline được **chuyển**, không xoá). `--diff` = đoạn user sửa giữa Gate 2 và Final → input của `/learn`. Ghi `publish-ledger.csv`. Exit 3 = bài không có outline ở đâu cả (Thesis / Information_Gain không được lưu). |
| `scripts/rotate_revision_log.py` | `revision-log.md` chỉ giữ 30 ngày; cũ hơn → `revision-log/YYYY-Qn.md`. Điểm QA ở `qa-score-log.csv`. |
| `scripts/weekly_review.py [--done backfill\|gsc slug…] [--unpublished]` | Báo cáo `/weekly` từ `publish-ledger.csv` + snapshot live (tự đối chiếu slug local ↔ slug live qua front matter `source:`): Final chưa live, bài cần backfill (gộp 1 spec), bài 28–56 ngày cần đo GSC, draft cũ. 0 network. |
| `scripts/slop_check.py <file> [-v] [--json]` · `--baseline [--csv f] [--top N]` · `--thresholds` | **Tầng B** — 13 rule `SLOP-*` thống kê (burstiness, rhythm_gap, evidence/100w, unanchored, vague, template_sim…). Bắt slop mà tầng A không thấy: bài sạch 100% từ cấm vẫn có thể phẳng nhịp, không bằng chứng. Ngưỡng **relative theo corpus DSC** (baseline 2026-10-16, 182 bài → `knowledge/3-pipeline/slop-audit-2026-10-16.md`). Gate: score < 80 = FAIL. Offline, 0 API call. |
| `scripts/market_facts.py --brief [--tickers …]` · `--ticker VCB` · `--index VNINDEX --years 2022,2026` · `--verify <file>` | **Script duy nhất có network trong pipeline viết.** OHLCV thật (VNDirect dchart) + danh sách mã niêm yết (SSI iboard), cache 24h ở `scripts/market-cache.json`. `--verify` bắt `FACT-index-wrong` (số chỉ số sai) / `FACT-ticker` (mã không niêm yết) / `FACT-stale` (mọi mốc cũ hơn 18 tháng). **Exit 3 = nguồn chết → KHÔNG chặn pipeline**, dùng dữ kiện cấu trúc thay thế. |
| `scripts/news_feed.py --topic "<kw>" [--days N]` · `--latest` · `--feeds` | RSS 6 nguồn (CafeF ×2, VnExpress, Vietstock, Tuổi Trẻ, Dân Trí), cache 6h. Dùng để tìm góc bài + mốc sự kiện **có ngày**; KHÔNG dùng để viết lại tin — nội dung DSC là evergreen. |
| `scripts/find_links.py "<kw>" [--exclude slug]` / `--backfill <slug>` | Tra `internal-links/anchor-index.md` + sitemap-cache (+ cột inlink ngữ cảnh từ snapshot live). `--backfill` quét **toàn bộ bài live** (`knowledge/raw/live`, 825 bài) tìm bài chưa link ngữ cảnh tới slug, kèm mục + đoạn gợi ý; bài chỉ link qua dòng Xem thêm được đánh dấu. `--finalized` = quét `3-finalized/` như cũ. `--add-anchor <slug> --anchor … --cluster …` = thêm 1 dòng vào `anchor-index.md` (không mở file 189 KB). |
| `scripts/sync_live.py [--only slugs] [--from-sf csv] [--show slug] [--compare slug] [--relink]` | **Nguồn sự thật cho bài đã publish.** Snapshot thân bài live mọi `/kien-thuc` + bài trong `link-clusters.json` → `knowledge/raw/live/html/<slug>.html` (1 block/dòng, git diff được) + `pages.csv` (words, link in/out, Xem thêm, CTA) + `links.csv` (from, to, anchor, kind, section). `--compare` = Final-*.md vs live (link thêm/gỡ trên CMS, độ lệch văn bản) — chạy trước `/optimize`. Stdlib, full ~3-4 phút; chỉ ghi file khi nội dung đổi. Khi nào chạy: xem `internal-linking/SKILL.md` §Mode: Live Snapshot. |
| `scripts/page_groups.py build [--show 3d\|3\|unassigned]` · `taxonomy` · `report [--dir D]` | **Nhóm bài để đo performance / audit theo batch.** `build` gán mọi bài live (`knowledge/raw/live/pages.csv`) vào 14 cụm → ~55 nhóm con → `knowledge/3-pipeline/page-groups.csv`; sửa gán sai ở `page-groups-overrides.csv`, mã CP → ngành ở `ticker-sector.csv`. `report` ghép GSC (MCP, page + page×query theo nhóm con) + GA4 (export Explore hoặc MCP Content Matrix) từ `knowledge/raw/audit/<ngày>/` → `page-audit.csv` (1 dòng/bài, nhãn `rank-drop`/`ctr-low`/`striking`/`engage-low`/`convert-low`/`dead`) + `group-performance.md`. Danh sách file cần có: `AUDIT_FILES` trong script. |
| `scripts/topical_map.py` | **Bản đồ cụm** `knowledge/3-pipeline/internal-links/topical-map.html`: cluster → nhóm con → bài (■ pillar · ◎ hub · ● bài, cỡ = clicks), màu theo link pillar/hub · Δ clicks · nhãn audit; bảng thứ tự audit; bấm nhóm = batch audit (deep-link `#5b`, `group-performance.md` link sang). Chạy lại sau `sync_live.py` / `page_groups.py report`. |
| `scripts/topic_status.py <slug> [--set S]` / `--find` / `--list` / `--summary` | Đọc/ghi 1 ô trạng thái trong topic-clusters.md. `<slug> --add --keyword … --cluster …` = thêm dòng mới. `--summary` = bảng cluster × trạng thái + bài chưa Finalized (input `/keyword-plan`). |
| `scripts/revision_log.py add <slug> --fix --pattern --rule [--scope]` · `brief [--since D\|--slug s]` · `mark-learn` | Ghi/đọc revision-log không mở file. `add` chặn trường > 400 ký tự (mục cũ 3 KB làm log 30 ngày phình 95 KB). `brief` = 1 dòng/mục từ lần `/learn` trước. |
| `scripts/persona.py P1-P4 [--part <mục>]` · `--matrix` · `--list` | In đúng 1 persona (~3 KB) / 1 mục (`bridge`, `tone`…) / ma trận CTA, thay cho đọc `personas.md`. |
| `scripts/dashboard_cache.py save <kind> [slug]` · `report <slug>` · `status` | Cache dùng chung cho **SEO Dashboard MCP** (GSC/GA4/Ads/cannibalization). Agent có MCP gọi tool → `save`; agent không có MCP (Antigravity chưa cấu hình, Cursor…) đọc `report`. `save pages` / `save page-query` ghi luôn `pages.csv` / `queries.csv` theo schema `sync_gsc.py` → `process_gsc.py`, `find_links.py --backfill` chạy không cần credentials. Playbook: `.antigravity/skills/seo-dashboard/SKILL.md` · cấu hình: `.antigravity/config/seo-dashboard-mcp.md`. 0 network. |
| `scripts/cta_audit.py <file\|slug\|URL>` / `--all [--ga4 csv]` / `--refresh` | Audit tầng chuyển đổi: banner, vị trí theo % thân bài, đoạn dẫn, link mở TK, CRO score. Nhận cả URL — ưu tiên file local, không có thì đọc snapshot live `knowledge/raw/live/html/` (thiếu / `--refresh` → tự `sync_live` trang đó). **Không dùng web-serp/Firecrawl cho URL dsc.com.vn.** Chỉ đọc, không ghi. |
| `scripts/md_to_cms_html.py <slug\|file.md> [--stdout]` | Chuyển `Final-*.md` sang HTML dán vào CMS (chế độ Source) → `knowledge/4-content/4-cms/<slug>.html`. Đúng markup live: `<h2><strong>`, ảnh bọc `<p style="text-align:center;">` và src **tương đối `/uploads/…`** (tự đổi từ `extgw.dsc.com.vn/eback/uploads/` — URL tuyệt đối bị lỗi trên CMS; còn ảnh tuyệt đối khác thì script cảnh báo), bảng `<figure class="table">`, link `target="_blank"`; banner HTML giữ nguyên; bỏ H1 (in Title/Meta/H1 ra console). Tự chạy trong `/approve`. Stdlib. |
| `scripts/optimize_instincts.py [--check] [--stats] [--show ID\|tag\|slug]` | Sinh lại `instincts.md` + `instincts-by-scope/` từ archive — **không cắt rule**. `--check` = gate (LONG > 450 ký tự / TAG-DUP / BUDGET > 8.000 / ORPHAN / SUPERSEDE). `--stats` = check của từng rule còn bắn ở bao nhiêu bài (từ `qa-check-log.csv`, ghi bởi `qa_lint --log`). `--show` = in đúng block rule theo ID / tag / ghi chú ARTICLE của 1 slug — thay cho đọc archive. |
| `scripts/serp_opportunities.py [--min-count N]` | Gom PAA + Related Searches từ cache SERP → `knowledge/3-pipeline/serp-opportunities.md` (chưa có bài / có bài chưa giữ PAA / DSC đang giữ). 0 API call. Input cho `/keyword-plan`, `/optimize`. |
| `.antigravity/skills/web-serp/scripts/serp_research.py "<kw>" [--top 10] [--extract 5] [--paa-depth N]` | SERP Google VN (DataForSEO, **có phí**) + PAA (kèm đáp án Google đang hiện + đối thủ nào có heading khớp) + Related Searches + extract competitor (local Scrapling parser, Jina fallback cho trang JS). **Digest mặc định gọn (~6–10 KB)**: cây heading + số từ mỗi đối thủ và block `Topic Coverage` gộp chung (thuật ngữ ≥ 3 đối thủ dùng = bắt buộc phủ, chủ đề con chung, nguồn họ trích; đã loại trang rác / trang DSC); `--full` = chi tiết từng đối thủ (dài gấp 3). Lưu thêm nội dung + nguồn trích của AI Overview khi API trả về. `--rebuild-background` = dựng lại `term-background.json` (từ vựng chung, dùng để lọc thuật ngữ). Cache 30 ngày ở `knowledge/raw/serp/` — không dùng `--no-cache` trừ khi user yêu cầu; `--paa-depth` tốn thêm, chỉ cho pillar. Keyword chưa có trong topic-clusters/sprint-backlog → script từ chối gọi API, cần `--force`. |
| `.antigravity/skills/internal-linking/scripts/sync_sitemap.py` | Cập nhật `sitemap-cache.json` từ sitemap live. |
| `scripts/link_plan.py candidates` · `build <spec.json>` · `verify <spec.json>` | Kế hoạch sửa link **bài đã publish** để sửa tay trên CMS: `candidates` liệt kê link redirect/chết/trỏ danh mục, bài cụm thiếu pillar/hub, bài traffic cao 0 inlink → viết spec JSON (op: wrap/replace/append/newp/href/unlink/remove) → `build` ra HTML (block Trước/Sau lấy từ snapshot live, xem trước, tick đã sửa) → sửa CMS + `sync_live` → `verify` báo mục nào đã lên live. Plan ở `internal-links/plans/`. |
| `.antigravity/skills/internal-linking/scripts/link_audit.py [--orphans]` | Audit internal link **trên site live** (từ snapshot) → `internal-links/dashboard.md` (tuân thủ cụm pillar/hub, bài 0 inlink ngữ cảnh, bài còn Xem thêm, anchor trùng) + `internal-links/link-graph.html` (graph tương tác + bảng, mở bằng trình duyệt). |
